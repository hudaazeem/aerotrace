# Aerotrace

AeroTrace is a web app I built to help people better understand how environmental conditions might affect their allergies. I was inspired to create AeroTrace because of my own experiences dealing with constant hay fever without knowing potential triggers. I wanted to make something that could help people who suffer from the same symptoms as me better understand their symptoms and how they may relate to the environment. By combining local pollen data, air quality information, and personal symptom tracking, AeroTrace makes it easier to identify potential patterns and make more informed decisions about daily activities. 

## Features
- **Pollen Data:** View local pollen levels and forecasts.
- **Air Quality:** Check local air quality and pollutant levels.
- **Symptom Tracker:** Log and review symptoms to identify potential patterns.

## Tech Stack
- **Frontend:** HTML, CSS, and JavaScript
- **Backend:** Node.js, Express
- **APIs:** Open-Meteo Air Quality API, Zippopotam.us API, and Google Pollen API
- **Storage:** Browser localStorage
- **Deployment:** Render
